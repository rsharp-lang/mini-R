## 用户需求

在为 R# 脚本做版本管理（CVS）时，保存新版本需要填写「版本变更说明」。本次优化：

- 在 WinForm（自定义对话框）与 HTML 界面各加一个「AI 生成」按钮，点击后把**新脚本与上一版本的差异**发给 LLM 生成变更说明并回填。
- 在 HTML 版本列新增只读区域，显示选中版本的完整变更说明。

## 关键决策（已与用户确认）

- WinForm：新建代码构建的 `CommentDialog`（多行文本框 + 「AI 生成」+ 确定/取消）替换 `Interaction.InputBox`。
- LLM 上下文：取「待保存新代码 + 上一版本代码」的差异，交给 LLM。
- 展示位置：HTML 版本列评论框下方的只读区域。

## 差异计算：复用 MyersDiff（已验证可用，零新增依赖）

- 模块：`G:\GCModeller\src\runtime\sciBASIC#\Data\MyersDiff\MyersDiff.vbproj`，RootNamespace=`Microsoft.VisualBasic.Data.MyersDiff`。
- **RDev.NET5.vbproj 第 117 行已 ProjectReference 该工程，且其依赖 Microsoft.VisualBasic.Core（第 118 行）也已存在**，故 `ScriptManagerView.vb` 只需 `Imports Microsoft.VisualBasic.Data.MyersDiff` 即可直接使用，**无需新增任何 ProjectReference**。
- 用法：

```
Dim differ As New MyersDiff()
Dim oldLines As String() = If(oldCode, "").LineTokens
Dim newLines As String() = If(newCode, "").LineTokens
Dim result As DiffResult = differ.Compare(oldLines, newLines)
' result.ToSummary()      → "旧/新行数、相同/删除/插入项、相似度"
' result.ToUnifiedDiff("上一版本.R", "当前版本.R", contextLines:=3) → 标准 unified diff
```

- 当 `result.Truncated = True`（差异超过 MaxEditDistance 上界）时退化为全删+全插，仍可读；prompt 备选降级为直接拼接新旧代码全文。

## 技术栈

- 宿主：VB.NET WinForms + WebView2（`ScriptManagerView.vb`，RDev.NET5.vbproj）。
- LLM：复用 `Ollama` 的 `LLMConfig.LoadDefault().CreateLLm()` → `Async Function Chat(prompt) As Task(Of LLMsResponse)`，结果取 `.output`，可设 `system_message`。
- 差异：`Microsoft.VisualBasic.Data.MyersDiff`（已引用）。
- 前端：纯 HTML/CSS/JS 嵌入资源，经 `postMessage` 桥通信。

## 实现方案

### 总体策略

复用现有消息桥：HTML 按钮发 `CvsOutgoing.SuggestComment`，宿主 `Dispatch` 调 `GenerateCommentAsync()`，再 `Post(CvsIncoming.CommentSuggestion, {comment})` 回填；WinForm 侧把同一 `GenerateCommentAsync`（签名 `Func(Of Task(Of String))`）注入对话框，在本地直接调用，不绕 WebView。两者共享「取代码→MyersDiff 算 diff→拼 prompt→调 LLM」逻辑。

### 关键技术决策

1. **自定义对话框用代码构建（无 Designer/resx）**：`Interaction.InputBox` 无法承载按钮；新建 `CommentDialog.vb` 在 `Sub New` 中以代码创建 `TextBox(Multiline)`/`Button` 并布局。
2. **diff 上下文（MyersDiff）**：

- 新代码 = `Await _editor.SaveScript()`；旧代码 = `db.GetVersionCode(scriptId, If(_editorVersionId, versionId))`。
- `oldLines/newLines = 文本.LineTokens`；`differ.Compare(...)`；prompt = `ToSummary()` + 空行 + `ToUnifiedDiff(...)`。
- 当任一为空或 `Truncated` 时，降级直接拼接两份代码（标注「上一版本」「当前版本」）。
- 系统提示要求模型输出中文、聚焦实质性修改的变更说明（2-4 句，不输出代码块）。

3. **VersionDetail 补传 comment**：`SelectVersion` 的 `Post` 字典新增 `comment`（来自 `VersionRecord.comment`），前端渲染只读区域；不新增消息类型。

### 可靠性

- LLM/MyersDiff 均为 IO/计算，宿主侧全部 `Await`；生成期间前端与 WinForm 按钮均禁用并显示「生成中...」。
- 配置缺失（`provider` 为空）/异常在 `Try/Catch` 内降级为 `RaiseStatus(..., "warn"/"error")` 并 `Return Nothing`，不抛出到 UI 线程。
- `LLMConfig.LoadDefault()` 默认路径 `App.ProductProgramData/llm.ini`。

### 实现注意事项

- 仅在 `_editor Is Nothing` 时提示「请先在代码编辑器中打开脚本」，与 `SaveVersion` 一致。
- `GenerateCommentAsync` 为 `Async Function ... As Task(Of String)`，`Return Nothing` 表示失败。
- `MyersDiff.Compare` 接受 `String()`；用 `String.LineTokens` 切分（Core 已引用）。
- 前端 `handlers[Incoming.VersionDetail]` 兼容 `comment` 为空（`（无变更说明）` 占位）。
- 不改动 `CvsDatabase`、`Models` 及其他无关消息分支。

## 目录/架构要点

- 复用既有「消息桥」与「VS Code Light+」三列布局主题，仅局部增量：
- 版本列评论区：`#versionComment` 与 `#btnSuggestComment`（次要按钮）同行；生成期按钮显示「生成中...」并禁用。
